# 需求：AI Agent 平台 v2

## 背景

当前平台是一个 Next.js 单体应用，包含 6 个 AI Agent（资讯收集、股票分析、点子王、知识库、MCU手册速读、MaaS选型助手）。所有功能硬编码，无用户系统，模型配置写死在代码中。

目标：升级为可部署到多个小公司内部的 **Agent 管理平台**，支持用户管理、Agent 配置、模型网关、用量监控。

## 用户角色

| 角色 | 描述 |
|------|------|
| **超级管理员** | 平台级管理，可管理所有租户、模型配置 |
| **租户管理员** | 管理本公司用户、配置可用 Agent、查看用量 |
| **普通用户** | 使用被授权的 Agent |

> 注：v1 阶段先实现单租户模式（管理员 + 普通用户），后续扩展多租户。

## 核心需求

### P0 - 用户系统
- [ ] 用户注册/登录（邮箱 + 密码）
- [ ] JWT Token 认证
- [ ] 角色权限：管理员 / 普通用户
- [ ] 管理员可禁用/启用用户账号

### P0 - Agent 管理
- [ ] 管理员可在后台配置哪些 Agent 可用
- [ ] 每个 Agent 可独立配置使用的模型
- [ ] Agent 配置持久化到数据库（不再硬编码）
- [ ] 普通用户只能看到已启用的 Agent

### P0 - 模型网关
- [ ] 统一的模型调用入口（替换各 Agent 直接调用）
- [ ] 支持配置多个模型 Provider（Mify API / 本地模型 / OpenAI 兼容接口）
- [ ] 默认 Provider：Mify（`https://api.llm.mioffice.cn/anthropic/v1`）
- [ ] 每次调用自动记录 Token 用量

### P1 - 用量监控
- [ ] 管理员后台展示 Token 用量统计
- [ ] 按 Agent 维度统计（哪个 Agent 用了多少 Token）
- [ ] 按用户维度统计（哪个用户用了多少 Token）
- [ ] 按时间维度（日/周/月）统计

### P1 - 管理员后台
- [ ] 独立的 `/admin` 路由
- [ ] 用户管理页面（列表、禁用/启用）
- [ ] Agent 管理页面（启用/禁用、模型配置）
- [ ] 模型 Provider 管理页面（增删改查）
- [ ] 用量统计仪表盘

### P2 - 数据隔离
- [ ] 用户的对话历史按用户隔离
- [ ] 知识库内容按用户隔离
- [ ] 管理员可查看所有用户数据

## 非功能需求

| 维度 | 要求 |
|------|------|
| **部署** | Docker 一键部署，支持离线环境 |
| **数据库** | PostgreSQL（从 SQLite 迁移） |
| **认证** | JWT，Token 有效期 24h，支持刷新 |
| **安全** | 密码 bcrypt 加密，API 需认证 |
| **性能** | 模型调用异步，不阻塞 UI |

## 暂不考虑

- 多租户隔离（v2 再做）
- OAuth/SSO 集成
- 付费计费系统
- Agent 市场/插件系统
